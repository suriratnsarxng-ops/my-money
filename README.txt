My Money V37

วิธีย้ายข้อมูลจากเว็บเดิมไปเว็บออนไลน์:
1) เปิดเว็บเดิมที่มีข้อมูล
2) กด 📥 สำรองข้อมูล และเก็บ my-money-backup.json
3) เปิดเว็บออนไลน์
4) กด 📤 นำเข้าข้อมูล แล้วเลือกไฟล์ my-money-backup.json
5) ระบบจะรวมข้อมูลด้วย ID และไม่ลบข้อมูลเดิมบนเครื่อง

Backup ครอบคลุม transactions, dueItems, installments, invoice history, รายชื่อผู้รับ/ผู้จ่าย และเลขบิล
